## Current Research

### Beyond Shared Geometry

**[Beyond Shared Geometry: Predictive Recovery, Exact Actions, and Registration Preference in Language-Model Representations](https://doi.org/10.5281/zenodo.24238471)**

This paper examines what successful transformation predictors reveal about language-model representations. It separates prediction in held-out contexts, compatibility with exact orthogonal group actions on fixed representation banks, and preference for prescribed state correspondences over alternatives that obey the same group laws.

The theory bounds the minimum fixed-bank prediction error under exact orthogonal action constraints. Weekday and square-corner experiments show that registration preference depends on retained dimension and state-invariant components. Accurate prediction alone does not establish the model's underlying computational mechanism.

[Paper](https://doi.org/10.5281/zenodo.24238471) · [Code, saved data and reproduction guide](https://github.com/yangpengchengstat/beyond-shared-geometry)

*2026 preprint · Code and retained experimental evidence released*

### Robust Multi-Objective Model Validation

**Robust Mixed-Variable NSGA-III Challenger Search for Less Discriminatory Tabular Models**

This project searches for alternative XGBoost models by jointly selecting features and tuning hyperparameters. It examines trade-offs among predictive performance, directional residual disparity, and sparsity across five public tabular benchmarks, with repeated-seed evaluation, calibration diagnostics, and threshold-sensitivity analysis.

[Code, benchmark results and reproduction guide](https://github.com/yangpengchengstat/robust-lda-nsga3)
